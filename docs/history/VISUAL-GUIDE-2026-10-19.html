Links read the same from both ends

New in 0.4.141. When a record's field points at a page (a meeting's attendees, a visit's doctor), that page now says so in its own property list: a row with an arrow, “← attended” or “← doctor of”, listing those records. Up to three show by name; more show as a count with the next date, which opens into a dated list. Names and days are plain grey, like every property name. The rows only read: to change a link, change the record that holds the field. A record's own row of properties now wraps onto more lines instead of being cut off.

Properties typed in the line

Type a field's first letters and :: at the end of the block (p:: lists every field, a::pri goes straight to attendees). A list opens under the property row, on the proposed value, with the reason beside it. Enter writes. Escape or leaving the block takes the typed letters back out. A field that takes several pages stays open. Since 0.4.136, ;; in place of :: also keeps the value in your sentence: deadline;;today leaves a link to the day, a person leaves a link to their page, free text stays as typed.

Proposals in the pills

While you type, the plugin pencils in what it can see: a person named in your words, a day such as “next fri”, the parent block's or page's project, the journal day. Tab takes the one with the hint and moves on; Shift+Tab passes it. After a write, a quiet undo ⌘z sits beside the value for seven seconds. After twenty takes the hint’s words go, but its tab key stays beside the value Tab takes next (0.4.138), so you can always see which one that is.

The link box

Select words and press ⌘⌥L (Link selected text to a page). Since 0.4.139 the box opens right under the words, not in the middle of the window, and the page stays usable; a click elsewhere or Escape closes it. Under your pages it lists up to five blocks: tagged blocks first, with their tag at the right, then any block once you type three letters, marked block. Make page shows only when nothing matches exactly, and never above a match. The key moved from ⌘⇧L in 0.4.142, because on a Mac that key also opened Safari.

Inside the code

One core and a set of parts, one file per area. The core watches the screen and the database; the parts put small marks on Logseq's elements; one fixed stylesheet draws from the marks.
