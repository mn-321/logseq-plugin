# Records

Everything in this folder is a **record**: written at a moment, dated, kept for its history, and not updated. None of
it is a plan or an instruction for a later session. Each file opens with a banner saying when it was written and what
became of it. What the plugin is today is `docs/STATE.md`; the owner's rulings and what was tried and rejected are
gathered in `DECISIONS-AND-RULINGS-2026-10-24.md`.
